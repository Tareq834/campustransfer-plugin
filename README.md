# Salesix

A Claude plugin for teams that recruit international students into Maltese colleges through education agents.

## What it does

- **Reviews CVU (Identita) query emails**: counts unique students, finds open issues, and works out the 5-working-day reply deadline.
- **Checks visa documents** against CVU requirements: insurance, financial means, sponsorship, passport, acceptance letter and flight ticket.
- **Runs a pre-submission checklist** to prevent CVU queries before a file is sent.

## How to use

Install the plugin, then ask Claude things like:

- "Review these CVU emails and list the open issues with deadlines."
- "Check this insurance certificate against CVU rules."
- "Run the pre-submission checklist on this student file."
